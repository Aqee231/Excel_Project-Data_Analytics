# 📊 Data Jobs Salary Analysis (Excel)

Two Excel projects analyzing real-world data science job postings from 2023 — one built as an interactive salary dashboard, the other as a deeper skills-and-pay analysis using Power Query, Power Pivot, and DAX.

## 📁 Projects

## 💡 Key Takeaways

- Senior-level and engineering roles command the highest median salaries; Analyst roles are consistently lower.
- More skills per posting correlates with higher pay, especially for Senior Data Engineer and Data Scientist roles.
- **SQL** and **Python** dominate as the most requested skills, with cloud platforms (AWS, Azure) close behind.
- Among individual skills, Python, Oracle, and SQL are tied to the highest median salaries.

## 🗂️ Dataset

Real-world data science job postings from 2023, covering job titles, salaries, locations, and required skills.
